InfoFill Privacy Policy

Last updated: June 21, 2026

```

InfoFill is a Chrome extension that helps users store reusable business information locally in their browser and use it to fill matching web form fields.

Data Storage

InfoFill stores saved business information in Chrome local extension storage on the user’s browser.

Saved information may include business name, website URL, phone number, address, email address, category, description, social links, service area, and other custom label-value fields added by the user.

No Server Storage

InfoFill does not send saved business information to a remote server.

InfoFill does not use a cloud database, cloud sync, analytics system, or external storage service to store business information.

No Sensitive Credential Storage

InfoFill is not designed to store passwords, API keys, tokens, cookies, sessions, private keys, or login credentials.

The extension attempts to skip sensitive labels during import where possible.

Form Filling

InfoFill only fills matching form fields after the user chooses a saved business information item and clicks Fill.

  • InfoFill does not submit forms automatically.
  • Users must review and submit forms themselves.
  • InfoFill avoids filling password fields, hidden fields, file upload fields, disabled fields, readonly fields, and invisible fields.

Permissions

InfoFill uses Chrome extension permissions only for its core purpose.

  • The storage permission is used to save business information locally in the browser.
  • The activeTab permission is used when the user manually runs the extension on the current page.
  • The scripting permission is used to detect and fill safe matching fields after user action.

InfoFill does not request broad host access.

Data Control

Users can create, edit, delete, import, and export saved business information.

Users can export JSON or TXT backups and can clear saved data from the extension.
```
